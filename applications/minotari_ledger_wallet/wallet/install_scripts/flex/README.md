# Minotari Ledger Wallet - Flex

This directory keeps the legacy Flex entry points. They now call the unified installer:

```bash
../install_minotari_ledger.py --model flex
```

From Windows PowerShell:

```powershell
.\install_ledger_win.ps1
```

From macOS or Linux:

```bash
./install_minotari_ledger_flex.sh
```
