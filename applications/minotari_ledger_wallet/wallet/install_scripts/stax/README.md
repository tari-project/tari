# Minotari Ledger Wallet - Stax

This directory keeps the legacy Stax entry points. They now call the unified installer:

```bash
../install_minotari_ledger.py --model stax
```

From Windows PowerShell:

```powershell
.\install_ledger_win.ps1
```

From macOS or Linux:

```bash
./install_minotari_ledger_stax.sh
```
