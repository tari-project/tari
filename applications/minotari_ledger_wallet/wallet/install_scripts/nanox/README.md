# Minotari Ledger Wallet - Nano X

This directory keeps the legacy Nano X entry points. They now call the unified installer:

```bash
../install_minotari_ledger.py --model nanox
```

From Windows PowerShell:

```powershell
.\install_ledger_win.ps1
```

From macOS or Linux:

```bash
./install_minotari_ledger_nanox.sh
```
