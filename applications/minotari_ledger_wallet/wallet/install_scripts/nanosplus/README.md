# Minotari Ledger Wallet - Nano S Plus

This directory keeps the legacy Nano S Plus entry points. They now call the unified installer:

```bash
../install_minotari_ledger.py --model nanosplus
```

From Windows PowerShell:

```powershell
.\install_ledger_win.ps1
```

From macOS or Linux:

```bash
./install_minotari_ledger_nanosplus.sh
```
